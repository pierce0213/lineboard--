## 线绘板 LineBoard v1.0.0 —— 首个正式版

**一个 HTML 文件，双击就能用的对称辅助绘图板 —— 为不会画画的人做的绘图工具。**

无框架、无构建、零依赖、离线可用；Windows / macOS / Linux / Android / iPadOS 全都能跑。

### ✨ 这是什么

想画一个立方体、一个房屋结构、一张示意图，却画不齐、画不正？线绘板把
**「画得正」交给程序，人只负责决定画什么**：

- **画不歪** —— 端点自动吸附格点与已有线条，立方体棱对棱、角对角
- **画得对称** —— 开镜像画一半，另一半实时长出来（镜像 / 四象限 / 径向 2–24 等分，轴心可拖）
- **立体感有保障** —— 30° 等轴测网格，斜棱比例永远是对的；按格填色填出的是菱形面片
- **不会画也行** —— 接上大模型，一句话（可附图）它替你画；画出来的是**可编辑的线条**，不是图片

### 🚀 30 秒上手

下载 `symmetry-draw.html`，双击用浏览器打开。完事。

想在线分享？把仓库推到 GitHub 后开启 **GitHub Pages**（Settings → Pages → main 分支），
即得免费公开链接，手机也能用。

### 🧩 v1.0.0 亮点

| 能力 | 说明 |
| --- | --- |
| 9 种绘制工具 | 直线 / 折线 / 箭头 / 矩形 / 椭圆 / 弧线 / 文本 / 橡皮 / 填格，快捷键 1–9 |
| 实时对称 | 左右 / 上下 / 四象限 / 中心 180° / 径向 N 等分，渲染期派生、不写入数据 |
| 等轴测网格 | 立体格 + 菱形面片填色，画正方体这类图形不再靠手感 |
| AI 生成 | 7 家模型预设 + 自定义中转；输出结构化绘图指令，可撤销、可继续编辑 |
| 图片转填格 | 纯本机像素化，四档精度（52 / 80 / 110 / 130 格），自动裁边、剔背景、保纵横比 |
| 自动保存 | 每 4 秒存浏览器本地；作品可导出 `.json`（压缩格式，旧版兼容）与 2× PNG |
| 跨平台 | 12 个平台场景 × 2 内核（Chrome / Edge）各 278 项断言 + 149 项功能回归全绿 |

### 🔐 隐私

这个项目**不需要任何密钥**也能用。AI 是可选增强：API Key 只存在你自己的浏览器
localStorage 里，请求由浏览器直连你填写的接口，不经过任何第三方服务器；
导出的 PNG / 存档 / 仓库源码都不含密钥。
